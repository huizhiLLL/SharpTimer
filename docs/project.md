# SharpTimer 项目状态

## 项目目标

SharpTimer 是一个专为智能魔方训练打造的原生 Windows 桌面计时器。项目目标是提供可靠的智能魔方连接、智能打乱推进、READY 后首转起表、复原完成自动保存成绩，以及围绕转动序列、步数、TPS 和分段复盘的数据分析体验。

手动计时保留为备用输入和调试路径，不再作为核心产品方向或主要功能卖点。

## 当前状态

已稳定或基本可用的能力：

- 智能魔方 READY 后首转起表、复原完成自动保存和 15 秒观察。
- session 管理、成绩保存、行详情弹窗、删除、基础统计分析区（best / worst / mean / completed）和成绩趋势线 / 分布柱状图。
- SQLite 本地持久化，成绩已记录来源、智能魔方转动序列、步数、TPS 和复盘元数据。
- 亮/暗主题、背景材质、显示精度和中英文界面设置。
- 智能打乱推进可选择“自动消失”或“变浅保留”，并支持调整打乱字体与虚拟魔方大小。
- 三页响应式布局（计时页、成绩页、设置页），支持窄 / 中 / 宽三档断点自适应。
- MoYu32、GAN v2/v3/v4 与 QiYi 系列智能魔方连接、状态/电量/转动事件解析、智能打乱推进和复原计时闭环。
- 智能魔方实时 3D 预览，支持 `facelets` 状态显示、拖动视角、基础层转动画和 MoYu32 gyro 姿态驱动视角。

智能魔方当前协议状态：

- MoYu32 系列已作为主要稳定链路使用，并已接入 gyro 四元数姿态事件用于实时预览视角。
- GAN v2/v3/v4 已完成基础接入；GAN v4 MOVE 按 72-bit chunk 循环解析，并保留 history request 和 facelets 重同步兜底，避免缓冲溢出时直接断链。
- QiYi 系列已完成基础接入；当前按验证实现使用 ECB 加密通信、名称推导 MAC 优先握手、历史转动补偿，并按状态包时间戳拆分当前步和未来步，避免 facelets 覆盖后续转动。
- 智能魔方 BLE 链路已具备系统断链感知、被动断链资源清理、写入串行化、有限自动重连和保活失败回收。

## 当前重点

- 对 MoYu32、GAN 与 QiYi 做真机长测，重点验证静置睡眠、走出范围、快速连续转动、复原中短暂丢包和自动重连后的状态恢复。
- 优化智能打乱推进的纠错提示。
- 围绕智能魔方成绩补充分段复盘、步数 / TPS 趋势和筛选能力。
- 补充智能魔方相关平台无关测试。
- 继续整理 `MainWindow.xaml.cs` 中较重的界面编排；三页已拆为独立 View，智能魔方连接控制器、打乱文本着色、蓝牙设备列表项构建已抽离。

## 暂不做

- 暂不重建 WinUI 项目结构或切换核心技术栈。
- 暂不把厂商 BLE 兼容性特例放到 UI 层。
- 暂不继续扩展通用手动计时器能力；手动路径仅保留为备用和调试入口。
- 暂不进入 `SwapChainPanel + Direct3D` 真实 3D 渲染路线；当前 Canvas 预览效果已满足近期需要。
- 暂不把尚未充分验证的智能魔方兼容性写成 README 对外稳定承诺。
