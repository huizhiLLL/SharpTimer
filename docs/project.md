# SharpTimer 项目状态

## 项目目标

SharpTimer 是一个支持智能魔方的原生 Windows 桌面魔方计时器。项目目标是在稳定本地计时体验的基础上，提供可靠的智能魔方连接、智能打乱推进、READY 后首转起表和复原完成保存成绩流程。

## 当前状态

已稳定或基本可用的能力：

- 手动计时、15 秒观察、`+2`、`DNF`。
- session 管理、成绩保存、行详情弹窗、罚时修改、删除、基础统计分析区（best / worst / mean / completed）和成绩趋势线 / 分布柱状图。
- SQLite 本地持久化。
- 亮/暗主题、背景材质、显示精度和中英文界面设置。
- 三页响应式布局（计时页、成绩页、设置页），支持窄 / 中 / 宽三档断点自适应。
- MoYu32、GAN v2/v3/v4 与 QiYi 系列智能魔方连接、状态/电量/转动事件解析、智能打乱推进和复原计时闭环。
- 智能魔方实时 3D 预览，支持 `facelets` 状态显示、拖动视角、基础层转动画和 MoYu32 gyro 姿态驱动视角。

智能魔方当前协议状态：

- MoYu32 系列已作为主要稳定链路使用，并已接入 gyro 四元数姿态事件用于实时预览视角。
- GAN v2/v3/v4 已完成基础接入；GAN v4 MOVE 按 72-bit chunk 循环解析，并保留 history request 兜底。
- QiYi 系列已完成基础接入；当前按验证实现使用 ECB 加密通信、名称推导 MAC 优先握手和历史转动补偿。

## 当前重点

- 打磨智能魔方断开重连、状态同步延迟和成绩保存体验；`docs/bluetooth-link-analysis.md` 已明确静默断连、保活失败和零重连问题。
- 优化智能打乱推进的纠错提示。
- 补充智能魔方相关平台无关测试。
- 继续整理 `MainWindow.xaml.cs` 中较重的界面编排；三页已拆为独立 View，智能魔方连接控制器、打乱文本着色、蓝牙设备列表项构建已抽离。

## 暂不做

- 暂不重建 WinUI 项目结构或切换核心技术栈。
- 暂不把厂商 BLE 兼容性特例放到 UI 层。
- 暂不进入 `SwapChainPanel + Direct3D` 真实 3D 渲染路线；当前 Canvas 预览效果已满足近期需要。
- 暂不把尚未充分验证的智能魔方兼容性写成 README 对外稳定承诺。
